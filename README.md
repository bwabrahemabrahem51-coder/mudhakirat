# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/aad8ec87-3ec6-457c-aa9f-037ae20866ed

## Run Locally

**Prerequisites:**  [Android Studio](https://developer.android.com/studio)


1. Open Android Studio
2. Select **Open** and choose the directory containing this project
3. Allow Android Studio to fix any incompatibilities as it imports the project.
4. Create a file named `.env` in the project directory and set `GEMINI_API_KEY` in that file to your Gemini API key (see `.env.example` for an example)
5. Remove this line from the app's `build.gradle.kts` file: `signingConfig = signingConfigs.getByName("debugConfig")`
6. Run the app on an emulator or physical device
7. If you have already published your app in AI Studio, please [request upload key reset](https://support.google.com/googleplay/android-developer/answer/9842756#zippy=%2Crequest-an-upload-key-reset) in Google Play Console.

# مذاكرتي — ملاحظات التحديث (Supabase + الأندرويد)

## ملفات الـ SQL (مجلد `supabase/`)
- `friends-setup.sql`: يفعّل الأصدقاء والرسائل والستريك المشترك، ويحذف الرسائل الأقدم من 7 أيام تلقائياً.
  شغّله مرة واحدة في Supabase > SQL Editor. آمن لإعادة التشغيل.
- الدوال تعتمد على `auth.uid()`، لذلك الأصدقاء يحتاج حساب مسجّل ومؤكَّد بالإيميل في Supabase.
  الدخول المحلي (زر «المتابعة بدون رمز») يشتغل للتطبيق نفسه، لكن الأصدقاء يعرض رسالة تطلب تسجيل الدخول بحساب مؤكَّد.
- إشعارات الـ Push اليومية تعتمد على جدول `push_subs` ودالتي `save_push` و`delete_push` من إعدادك السابق (`setup-ready.sql`)، وهي غير مضمّنة هنا.

## ما الذي تغيّر في `index.html`
- الأصدقاء يستخدم نسخة الويب الأحدث (الكود يتولّد على السيرفر ولا يُرسل الإيميل).
- محفوظ من نسخة الأندرويد: الإشعارات عبر `AndroidBridge`، وتخطي رمز التحقق، وتسجيل الدخول المحلي.
- رسالة جديدة تظهر بتبويب الأصدقاء إذا ما كان هناك حساب سحابي مؤكَّد.

## بناء الـ APK
1. افتح المشروع بـ Android Studio.
2. اضغط Build > Build APK(s).
3. عند أي تعديل على الموقع: انسخ `index.html` و`sw.js` الجديدين إلى `app/src/main/assets/` ثم أعد البناء.

## إشعارات الخلفية (أندرويد)
- إشعار انتهاء المؤقّت والتذكير اليومي يصلان حتى لو التطبيق بالخلفية أو مغلق، عبر منبّهات النظام (`AlarmManager`).
- الملفات الجديدة: `AlarmScheduler.kt` و`AlarmReceiver.kt` و`BootReceiver.kt` و`Notifier.kt`.
- بعد إعادة تشغيل الجهاز أو تحديث التطبيق، المنبّهات المحفوظة ترجع تلقائياً.
- ما يوصل إشعار مكرر: لما يكون التطبيق مفتوحاً تتولّى الصفحة التنبيه بنفسها.
- تنبيهات الأصدقاء («خلّص صديقك وقته» والرسائل) تحتاج التطبيق مفتوحاً أو بالخلفية القريبة، لأنها تعتمد على فحص دوري. للوصول الكامل وهو مغلق يلزم Firebase Cloud Messaging.
- ارتفع رقم الإصدار إلى 1.1 (versionCode 2) حتى يُثبَّت فوق النسخة القديمة.

# إشعارات الأصدقاء عبر FCM (بدون OneSignal)
1. `app/google-services.json` موجود (مشروع Firebase: `mudhakirati-814db`).
2. شغّل `supabase/fcm-setup.sql` في Supabase > SQL Editor.
3. انشر الدالة: `supabase functions deploy send-push --no-verify-jwt`
4. الأسرار: `supabase secrets set FCM_SERVICE_ACCOUNT="$(cat service-account.json)" WEBHOOK_SECRET=<كلمة-سر-عشوائية>`
   (لا تضع ملف الـ Service Account داخل المشروع ولا ترفعه).
5. Supabase > Database > Webhooks: جدول `fr_messages`، حدث Insert، النوع Supabase Edge Functions، الدالة `send-push`،
   وأضف هيدر `x-webhook-secret` بنفس قيمة WEBHOOK_SECRET.

# بناء الـ APK على GitHub (بدون كمبيوتر)
1. ارفع كل ملفات المشروع لمستودع **خاص (Private)** (المفتاح `debug.keystore` موجود عمداً حتى يبقى توقيع التطبيق ثابت وتتحدّث النسخ فوق بعض).
2. تبويب **Actions** ← **Build APK** ← **Run workflow** (يشتغل تلقائياً مع كل رفع أيضاً).
3. بعد ~5-10 دقائق: تبويب **Releases** ← آخر Build ← نزّل `mudhakirati.apk` وثبّته.
4. لو عندك نسخة قديمة من AI Studio احذفها أول (التوقيع يختلف).

# الترتيب الأسبوعي العام بالنقاط
- شغّل `supabase/weekly-board-setup.sql` مرة وحدة بـSupabase > SQL Editor (بعد `friends-setup.sql` و`moderation-setup.sql`). آمن لإعادة التشغيل، ويحذف دالة `get_weekly_board` القديمة (أصدقاء فقط).
- الترتيب **لكل مستخدمي التطبيق**، لكنه **اختياري**: المستخدم يضغط «انضم للترتيب». يظهر **الاسم والصورة والنقاط فقط**، ولا يرجع الـID من السيرفر أبداً.
- النقاط: **نقطة لكل دقيقة مذاكرة + 10 مكافأة لكل يوم فيه إنجاز**، تُحسب على الجهاز وتُرسل عبر `sync_points`، والسيرفر يحدّها بـ1450 لليوم ويقبل تواريخ آخر ~9 أيام فقط.
- يعرض أعلى 30 + ترتيب المستخدم لو برّا الأعلى 30. أسهم لآخر 4 أسابيع. الأسبوع يبدأ السبت بالعربي والاثنين بالإنجليزي.

# مساحتي: 4 تبويبات (الجدول | الأصدقاء | التحديات | التصنيف)
- **الجدول**: وبأسفله تبويب داخلي «الملاحظات» (يعرض الملاحظات فقط).
- **الأصدقاء**: دايركت فقط (طلبات، دردشة، ستريك مشترك). انشال صندوق «شنو راح تسوي» من هنا.
- **التصنيف**: الترتيب الأسبوعي العام (اختياري، اسم + صورة + نقاط فقط).
- **التحديات**: الكروبات والرومات وتحدي الأصدقاء.

## الكروبات والرومات (`supabase/groups-setup.sql`)
شغّله مرة وحدة بعد `friends-setup.sql` و`moderation-setup.sql` و`weekly-board-setup.sql`. آمن لإعادة التشغيل.
- كروب دائم: حد أقصى 3 تنشئها و10 تنضم لها، و30 عضو لكل كروب. الدخول بكود 8 خانات عشوائية (مع حد المحاولات الغلط المشترك مع الأصدقاء) أو بإضافة المنشئ من قائمة أصدقائه. الأدمن يقفل الكود أو يغيّره أو يطرد.
- روم داخل الكروب باسم، **عام** (كل أعضاء الكروب) أو **خاص** (بدعوة). ينحذف بعد 30 دقيقة بدون نشاط والكروب يبقى.
- 🟢 وميض أخضر: يدرس الآن (من «ابدأ» داخل الروم، أو تلقائياً إذا شغّل مؤقّت التطبيق وهو بالروم). 🔴 وميض أحمر: توقّف (إيقاف المؤقّت أو «توقّفت»)، أو انقطعت إشارة الحياة أكثر من 15 دقيقة. ⚪ انتهى وقته.
- رسائل الكروب والروم: بدون حد حروف عملي (سقف تقني 1000)، و**30 رسالة باليوم لكل شخص** بمجموع كل الكروبات (تتصفّر منتصف الليل بتوقيت بغداد). تُحذف بعد 7 أيام.
- الإبلاغ 🚩 يوصل لأدمن الكروب (تبويب التحديات > الكروب > البلاغات)، ونسخة تروح `fr_reports` لك.
- لا يرجع كود (ID) ولا uid لأي واجهة، والإجراءات على الأعضاء تتم برمز عشوائي (`ref`).
- **تحدي الأصدقاء**: تحدٍّ 1 ضد 1 لمدة 3 أو 7 أيام بنفس النقاط. الصديق يقبل أو يرفض.
- منشئ الروم (حتى لو مو أدمن) يشوف بلاغات رومه من زر «البلاغات» داخل الروم، ويقدر يطرد العضو من رومه فقط.
- `VER` بـ`sw.js` صار `mudhakirati-v9-51`.

## تحديث إضافي (حظر، ترتيب الكروب، إشعارات)
- **الحظر 🚫**: من قائمة الأعضاء أو من رسالة بالدردشة. يخفي رسائل الطرفين لبعض، ويفك الصداقة، ويشيل التحديات بينهم. ما في فك حظر بالتطبيق حالياً (مثل حظر الأصدقاء الموجود).
- **ترتيب الكروب 🏆**: نقاط الأسبوع لأعضاء الكروب فقط (آخر 4 أسابيع). نقاطك تظهر لأعضاء الكروب، وهذا مذكور بـ`privacy.html`.
- **إعادة تسمية الكروب** للأدمن، و**تعيين/إزالة أدمن** للمنشئ فقط (⭐). إذا طلع المنشئ تنتقل الملكية لأقدم أدمن.
- **إشعارات (FCM)** عند: إضافتك لكروب، وصول تحدٍّ، قبول تحدّيك. تحتاج:
  1. إعادة نشر الدالة: `supabase functions deploy send-push` (الملف `supabase/functions/send-push/index.ts` تحدّث).
  2. **Webhook جديد** (Insert) على جدول `fr_notifs` بنفس الـURL ونفس هيدر `x-webhook-secret` اللي عملته لـ`fr_messages` و`fr_requests`. بدونه التطبيق يشتغل عادي بس بدون هذي الإشعارات.
- الدردشة تتحدّث كل 5 ثواني داخل الروم، و10 ثواني بباقي الشاشات (مو لحظية).
